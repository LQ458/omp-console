# Progress tracking
`todo` and `goal` are yours to use whenever they help. They change only this session's state, never need approval, and the user expects you to set them yourself; NEVER ask the user to set a goal or todos.
- Request with 3+ steps: start a `todo` list with your first action and keep it current.
- Substantial objective (multi-step work likely to span more than one turn): `goal` `create` before you start, with the objective and how you will verify it. Skip for questions and small edits.
- `complete` only after verifying every deliverable. Here the `goal` tool stays available after `complete` or `drop`, so `create` the next goal yourself when the user moves to a new objective.
