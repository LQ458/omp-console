omp-console now runs natively on Windows, and the first minutes are easier: a short tour, a clearer folder picker, and install guides in English and Chinese.

## Install

1. **Install the background service** on your computer: follow the [install guide](https://github.com/LQ458/omp-console/blob/main/docs/INSTALL.md) ([中文](https://github.com/LQ458/omp-console/blob/main/docs/zh-CN/INSTALL.md)), or paste the [agent install prompt](https://github.com/LQ458/omp-console/blob/main/docs/INSTALL-WITH-AN-AGENT.md) ([中文](https://github.com/LQ458/omp-console/blob/main/docs/zh-CN/INSTALL-WITH-AN-AGENT.md)) into omp, Claude Code, or Codex. macOS and Linux use `scripts/install.sh`; Windows uses `scripts/install.ps1` in PowerShell (no WSL, no administrator rights).
2. **Open it** at `http://127.0.0.1:7490`, or install a desktop app below. Then follow [Get started](https://github.com/LQ458/omp-console/blob/main/docs/GETTING-STARTED.md) ([中文](https://github.com/LQ458/omp-console/blob/main/docs/zh-CN/GETTING-STARTED.md)).

## Desktop apps

| System | Download |
|---|---|
| macOS, Apple Silicon | `omp-console_0.2.0_macos-arm64.zip` |
| Windows 10/11, x64 | `omp-console_0.2.0_x64-setup.exe` or `omp-console_0.2.0_x64_en-US.msi` |
| Debian/Ubuntu | `omp-console_0.2.0_amd64.deb` (x64) or `omp-console_0.2.0_arm64.deb` |
| Other Linux | `omp-console_0.2.0_amd64.AppImage` (x64) or `omp-console_0.2.0_aarch64.AppImage` |

The apps are not signed yet. First launch on macOS: **System Settings → Privacy & Security → Open Anyway**. On Windows: **More info → Run anyway** in the SmartScreen prompt. Check downloads against `SHA256SUMS.txt`.

## What's new

- **Native Windows.** The service, sessions and installer run on Windows 10/11 without WSL. `install.ps1` builds the app, protects `%USERPROFILE%\.omp-console` so only you and the system can read it, adds the `omp-console` command, and starts the service at sign-in through a per-user scheduled task. Windows paths (`C:\…`, network shares) work across the app.
- **First-visit tour.** Five short steps show where sessions are, how to start one, how to steer it, and where Settings and phone pairing live. Replay it from Settings → **Show tour**.
- **Clearer folder picker.** Starting a session opens a dialog: recent projects, a folder browser starting at your home folder, **New folder**, and **Type a path** for full paths.
- **Docs in plain English and Chinese**, including a getting-started guide.
- Usage countdowns stay current while the panel is open, and `/usage` results no longer count down from the wrong time.
- Rerunning the installer after `git pull` restarts the service on Linux and Windows, so updates take effect.

## Known limits

- Moving projects between computers still needs the macOS app.
- Phone access from Windows is untested; keeping a Windows computer awake during an Overnight run is not supported yet.
- Intel Macs and Windows on Arm have no prebuilt app.
