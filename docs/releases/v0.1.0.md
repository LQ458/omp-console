First preview of omp-console: a self-hosted control room for your [omp](https://github.com/can1357/oh-my-pi) coding agents, in the browser, a desktop app, or on your phone.

## Install

omp-console has two parts: a background service that runs your sessions, and a window to look at them.

1. **Install the service** on your Mac or Linux computer: follow the [install guide](https://github.com/LQ458/omp-console/blob/main/docs/INSTALL.md), or paste the [agent install prompt](https://github.com/LQ458/omp-console/blob/main/docs/INSTALL-WITH-AN-AGENT.md) into omp, Claude Code, or Codex and let it do the steps.
2. **Open it** at `http://127.0.0.1:7490` in any browser, or install the desktop app below (optional).

## Desktop apps

| System | Download |
|---|---|
| macOS, Apple Silicon | `omp-console_0.1.0_macos-arm64.zip` |
| Debian/Ubuntu | `omp-console_0.1.0_amd64.deb` (x64) or `omp-console_0.1.0_arm64.deb` |
| Other Linux | `omp-console_0.1.0_amd64.AppImage` (x64) or `omp-console_0.1.0_aarch64.AppImage` |

The macOS app is not notarized yet: on first launch open **System Settings → Privacy & Security** and click **Open Anyway**. Check downloads against `SHA256SUMS.txt`.

**Windows:** a native Windows version is in progress and will come in the next release.

## What's included

- Tiled session panes, a live agent graph, steering, and status for omp sessions.
- First-run checklist: omp install, model sign-in, existing terminal sessions, Claude Code history.
- Terminal omp sessions open as copies; the originals are never changed. Claude Code and Codex conversations can be imported.
- Pair browsers and phones with one-time codes; phone access over Tailscale Serve.
- Embedded omp 18.13.2, kept close to upstream by a small, reproducible patch set.

## Updating

From your checkout: `git pull`, then rerun the installer with the same option (`./scripts/install.sh --launchd` on macOS, `--systemd` on Linux).
