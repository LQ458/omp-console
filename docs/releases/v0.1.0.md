First preview of omp-console: a self-hosted control room for your [omp](https://github.com/can1357/oh-my-pi) coding agents, in the browser, a desktop app, or on your phone.

## Install

omp-console has two parts: a background service that runs your sessions, and a window to look at them.

1. **Install the service** from source. Follow the [step-by-step guide](https://github.com/LQ458/omp-console/blob/main/docs/INSTALL.md), or paste the [agent install prompt](https://github.com/LQ458/omp-console/blob/main/docs/INSTALL-WITH-AN-AGENT.md) into omp, Claude Code, or Codex and let it do the steps. macOS and Linux run it natively; Windows runs it inside WSL 2.
2. **Open it** at `http://127.0.0.1:7490` in any browser, or install a desktop app below (optional).

## Desktop apps

| System | Download |
|---|---|
| macOS, Apple Silicon | `omp-console_0.1.0_macos-arm64.zip` |
| Windows 10/11, x64 | `omp-console_0.1.0_x64-setup.exe` or `omp-console_0.1.0_x64_en-US.msi` |
| Debian/Ubuntu | `omp-console_0.1.0_amd64.deb` or `omp-console_0.1.0_arm64.deb` |
| Other Linux | `omp-console_0.1.0_amd64.AppImage` or `omp-console_0.1.0_aarch64.AppImage` |

The apps are not signed or notarized yet. First launch on macOS: **System Settings → Privacy & Security → Open Anyway**. On Windows: **More info → Run anyway** in the SmartScreen prompt. Check downloads against `SHA256SUMS.txt`.

## What's included

- Tiled session panes, a live agent graph, steering, and status for omp sessions.
- First-run checklist: omp install, model sign-in, existing terminal sessions, Claude Code history.
- Terminal omp sessions open as copies; the originals are never changed. Claude Code and Codex conversations can be imported.
- Pair browsers and phones with one-time codes; phone access over Tailscale Serve.
- Embedded omp 18.13.2, kept close to upstream by a small, reproducible patch set (`scripts/sync-omp.ts`).

## Known limits

- Windows needs WSL 2 for the service, and an Ubuntu window must stay open while you use it. A native Windows service is planned.
- Intel Macs: no prebuilt app; build it with `./scripts/install.sh --launchd --app`.
- Windows on Arm and phone access from Windows/WSL are untested.
